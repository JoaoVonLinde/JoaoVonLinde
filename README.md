### Spacenik — Plataforma SaaS de cursos

Plataforma onde criadores e instituições podem criar conta, gerenciar conteúdo e vender cursos online com pagamento integrado.

**O que implementei:**
- Autenticação com JWT
- Dashboard administrativo
- Integração de pagamentos (Stripe / Asaas)
- Gestão de usuários e conteúdo
- Funcionalidades com IA

**Stack:** React · Next.js · Node.js · NestJS · PostgreSQL · Docker
